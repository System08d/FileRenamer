File Renamer — User Guide
=

WHAT THE APPLICATION DOES
-------------------------
File Renamer is a program for bulk renaming of files
according to a given pattern (rule). The application does
NOT modify or delete the original files: it creates renamed
copies of them in a separate folder that you specify
yourself. This is done to eliminate the risk of accidentally
damaging or losing the originals.

-----------------------------------------------------
HOW TO USE THE APPLICATION
-----------------------------------------------------

1. "Select folder" button
   Specifies the folder containing the original files to be
   renamed. After selection, the path to the folder is
   displayed below the button (instead of the text "Folder
   not selected"). The files found in the folder will appear
   in the list on the right.

2. "Select folder for copies" button
   Specifies the folder where the renamed copies of the
   files will be saved. After selection, the path is
   displayed below the button (instead of the text "Copies
   folder not selected"). It is recommended to choose a
   folder different from the source folder.

3. File list (on the right)
   Shows the files found in the selected source folder.
   This is a preview of what will be processed.

4. "Renaming method" drop-down list
   This is where you select the pattern (rule) by which the
   file copies will be renamed. Below, it is described which
   fields need to be filled in for each method.

5. "Pattern text" field
   A free text field whose value is used depending on the
   selected renaming method:
     - a base word for numbering (for example, "photo" will
       produce the names photo1, photo2, photo3...);
     - prefix text (added to the beginning of the name);
     - suffix text (added to the end of the name, before the
       extension);
     - a combination of characters to be removed from the
       name.
   For methods that do not need this text (for example,
   simple numbering 1, 2, 3 or a random number), the field
   can be left empty.

6. "Number of characters" field
   Used only for the "remove characters from the beginning
   or end of the name" method. Here you enter the number of
   characters to cut off from the file name (not counting
   the extension).

7. "Side" drop-down list
   Used together with the "Number of characters" field: it
   specifies from which side of the file name the characters
   are cut off — from the beginning or from the end.

8. "Rename" button
   Starts the process: for each file in the source folder,
   a copy with a new name (according to the selected method)
   is created in the copies folder.

9. Status bar at the bottom (for example, "Done")
   Shows the current state: ready to work, successful
   completion, or an error message.

-----------------------------------------------------
GOOD TO KNOW
-----------------------------------------------------
- The original files are never modified — the program works
  only with copies in a separate folder.
- Before clicking "Rename", make sure that both the source
  folder and the copies folder are selected.

End of guide

File Renamer — Инструкция пользователя
=

ЧТО ДЕЛАЕТ ПРИЛОЖЕНИЕ
---------------------
File Renamer — программа для массового переименования файлов
по заданному паттерну (правилу). Приложение НЕ изменяет и НЕ
удаляет исходные файлы: оно создаёт их переименованные копии
в отдельной папке, которую вы указываете сами. Это сделано,
чтобы исключить риск случайно повредить или потерять
оригиналы.

-----------------------------------------------------
ПОРЯДОК РАБОТЫ С ПРИЛОЖЕНИЕМ
-----------------------------------------------------

1. Кнопка "Выбрать папку"
   Указывает папку с исходными файлами, которые нужно
   переименовать. После выбора под кнопкой отображается
   путь к папке (вместо надписи "Папка не выбрана").
   Найденные в папке файлы появятся в списке справа.

2. Кнопка "Выбрать папку для копий"
   Указывает папку, куда будут сохранены переименованные
   копии файлов. После выбора под кнопкой отображается путь
   (вместо надписи "Папка для копий не выбрана").
   Рекомендуется выбирать папку, отличную от исходной.

3. Список файлов (справа)
   Показывает файлы, найденные в выбранной исходной папке.
   Это предварительный просмотр того, что будет обработано.

4. Выпадающий список "Способ переименования"
   Здесь выбирается паттерн (правило), по которому будут
   переименованы копии файлов. Ниже указано, какие поля
   нужно заполнять для каждого способа.

5. Поле "Текст для паттернов"
   Свободное текстовое поле, значение которого используется
   в зависимости от выбранного способа переименования:
     - слово-основа для нумерации (например, "photo" даст
       имена photo1, photo2, photo3...);
     - текст префикса (добавляется в начало имени);
     - текст суффикса (добавляется в конец имени, перед
       расширением);
     - сочетание символов, которое нужно убрать из имени.
   Для способов, где этот текст не нужен (например, простая
   нумерация 1, 2, 3 или случайное число), поле можно
   оставить пустым.

6. Поле "Кол-во символов"
   Используется только для способа "убрать символы с начала
   или конца имени". Здесь указывается число символов,
   которое нужно отрезать от имени файла (без учёта
   расширения).

7. Выпадающий список "Сторона"
   Используется вместе с полем "Кол-во символов": указывает,
   с какой стороны имени файла отрезать символы — с начала
   или с конца.

8. Кнопка "Переименовать"
   Запускает процесс: для каждого файла из исходной папки
   создаётся копия с новым именем (по выбранному способу)
   в папке для копий.

9. Статусная строка внизу (например, "Готово")
   Показывает текущее состояние: готовность к работе,
   успешное завершение или сообщение об ошибке.

-----------------------------------------------------
ВАЖНО ЗНАТЬ
-----------------------------------------------------
- Исходные файлы никогда не изменяются — программа работает
  только с копиями в отдельной папке.
- Перед нажатием "Переименовать" убедитесь, что выбраны
  и исходная папка, и папка для копий.

Конец инструкции

File Renamer — Guía del usuario
=

QUÉ HACE LA APLICACIÓN
----------------------
File Renamer es un programa para el renombrado masivo de
archivos según un patrón (regla) determinado. La aplicación
NO modifica ni elimina los archivos originales: crea copias
renombradas de ellos en una carpeta aparte que usted mismo
indica. Esto se ha diseñado así para eliminar el riesgo de
dañar o perder accidentalmente los originales.

-----------------------------------------------------
ORDEN DE TRABAJO CON LA APLICACIÓN
-----------------------------------------------------

1. Botón "Seleccionar carpeta"
   Indica la carpeta con los archivos originales que se
   deben renombrar. Tras la selección, debajo del botón se
   muestra la ruta de la carpeta (en lugar del texto
   "Carpeta no seleccionada"). Los archivos encontrados en
   la carpeta aparecerán en la lista de la derecha.

2. Botón "Seleccionar carpeta para copias"
   Indica la carpeta donde se guardarán las copias
   renombradas de los archivos. Tras la selección, debajo
   del botón se muestra la ruta (en lugar del texto
   "Carpeta de copias no seleccionada"). Se recomienda
   elegir una carpeta distinta de la de origen.

3. Lista de archivos (a la derecha)
   Muestra los archivos encontrados en la carpeta de origen
   seleccionada. Es una vista previa de lo que se va a
   procesar.

4. Lista desplegable "Método de renombrado"
   Aquí se elige el patrón (regla) según el cual se
   renombrarán las copias de los archivos. A continuación
   se indica qué campos hay que rellenar para cada método.

5. Campo "Texto para patrones"
   Campo de texto libre cuyo valor se utiliza según el
   método de renombrado elegido:
     - palabra base para la numeración (por ejemplo,
       "photo" dará los nombres photo1, photo2, photo3...);
     - texto del prefijo (se añade al principio del
       nombre);
     - texto del sufijo (se añade al final del nombre,
       antes de la extensión);
     - combinación de caracteres que se debe eliminar del
       nombre.
   Para los métodos en los que no se necesita este texto
   (por ejemplo, la numeración simple 1, 2, 3 o el número
   aleatorio), el campo puede dejarse vacío.

6. Campo "Cantidad de caracteres"
   Se utiliza solo para el método "eliminar caracteres del
   principio o del final del nombre". Aquí se indica el
   número de caracteres que se deben recortar del nombre
   del archivo (sin contar la extensión).

7. Lista desplegable "Lado"
   Se utiliza junto con el campo "Cantidad de caracteres":
   indica por qué lado del nombre del archivo se recortan
   los caracteres: por el principio o por el final.

8. Botón "Renombrar"
   Inicia el proceso: para cada archivo de la carpeta de
   origen se crea una copia con el nuevo nombre (según el
   método elegido) en la carpeta de copias.

9. Barra de estado en la parte inferior (por ejemplo,
   "Listo")
   Muestra el estado actual: preparado para trabajar,
   finalización correcta o mensaje de error.

-----------------------------------------------------
IMPORTANTE SABER
-----------------------------------------------------
- Los archivos originales nunca se modifican — el programa
  trabaja solo con copias en una carpeta aparte.
- Antes de pulsar "Renombrar", asegúrese de que estén
  seleccionadas tanto la carpeta de origen como la carpeta
  de copias.

Fin de la guía
